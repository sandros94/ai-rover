# Jev Rover

A community-steered autonomous rover on procedurally generated Martian terrain. Nobody drives it: signed-in users propose the next destination and like each other's proposals; the server plans and simulates the drive; browsers watch it unfold and can replay any part of the journey.

Showcase of: TypeSafe's Jev (System One judgments), Nuxt 5 nightly, Nuxt UI, `unauth` + `unjwt` + `unsecure` sessions with GitHub and AT Protocol sign-in, valibot, Netlify (Database, Blobs, CDN).

Status: research and design. See `docs/vision.md` (story), `docs/plan.md` (dependency-ordered build plan), `docs/decisions.md` (settled decisions and open questions), `docs/untested-ledger.md` (known unknowns), `docs/research/` (evidence).
